# Mac Grammar Fixer (Powered by Gemini)

A lightweight tool to fix grammar and spelling in **any application** on macOS using a global keyboard shortcut. Powered by Google's Gemini API.

## 🚀 Setup

### 1. Prerequisites
*   **Python 3** installed on your Mac.
*   A **Gemini API Key** from [Google AI Studio](https://aistudio.google.com/).

### 2. Installation
1.  Clone or download this repository.
2.  Open a terminal in the folder and run the setup script:
    ```bash
    chmod +x setup.sh
    ./setup.sh
    ```
3.  **Add your API Key**:
    *   The script created a file named `.gemini_key`.
    *   Open it and paste your API key inside.

### 3. Create the Mac Shortcut
To use this anywhere, we'll create a macOS **Quick Action**.

1.  Open **Automator** app.
2.  Select **New Document** -> **Quick Action**.
3.  Configure:
    *   Workflow receives current **text** in **any application**.
    *   Check **Output replaces selected text**.
4.  Add **Run Shell Script** action.
    *   Shell: `/bin/bash`
    *   Pass input: **as arguments**
    *   **Code**: Paste the path to the `run_fixer.sh` file generated by the setup script.
        ```bash
        # Example (The setup script will give you the exact path):
        /Users/yourname/path/to/repo/run_fixer.sh "$1"
        ```
5.  Save as **"Fix Grammar"**.

### 4. Assign Keyboard Shortcut
1.  **System Settings** -> **Keyboard** -> **Keyboard Shortcuts** -> **Services**.
2.  Find **"Fix Grammar"** under **Text**.
3.  Assign a key (e.g., `Cmd + Shift + G`).

## 🛠️ How it Works
*   `grammar_fixer.py`: The core logic that sends text to Gemini.
*   `setup.sh`: Installs dependencies and generates a custom `run_fixer.sh` for your machine.
*   `run_fixer.sh`: (Generated) A wrapper script with absolute paths, ensuring Automator can find Python and your API key.
